About

Memorable Colours is a system for turning 16-bit colours into human-readable names that are easy to remember, communicate, and reuse. While values like "#1b1d44" or "(27, 29, 68)" are exact, they are difficult for humans to recall or discuss. Names like "Gloomy Rich Denim" are not.

That mapping takes 16-bit HSV colours (0-255 hue, 0-15 saturation, 0-15 value) and uses a dictionary to map each value to a relevant word. This allows the entire colour spectrum to be encoded into 3-4 word phrases, and converted back into RGB and Hex for display. The result is easy to remember, easy to share, and still precise enough for consistent colour work.
